### 🔭 Research & code

Historic masonry structures are irregular, and their surveys – laser scans and photogrammetry – are a long way from a mesh that can be analysed. My work turns these surveys into finite element models directly: closed surfaces, checked element quality and as little manual repair as possible. Before my MSc I spent seven years in heritage restoration practice, surveying historic masonry buildings, mapping their damage and preparing restoration drawings.

| Project | Description |
|---|---|
| **TetraFEM** | An Abaqus/CAE plug-in that turns laser or photogrammetric scans of archaeological structures into tetrahedral finite element models. Python (PyMeshLab, NumPy, SciPy). Paper in preparation; the code is not public yet. |

👯 I develop TetraFEM with [Giovanni Castellazzi](https://github.com/gcastellazzi) and [Antonio Maria D'Altri](https://www.unibo.it/sitoweb/am.daltri) at DICAM, University of Bologna.
